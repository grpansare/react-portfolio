# Ganesh Pansare — Portfolio

Personal portfolio of **Ganesh Pansare**, Junior Software Engineer at humancloud (Pune).
Full stack developer working with React, Angular, Spring Boot, microservices, Kafka and Kubernetes.

**Sections:** About · Experience · Projects · Skills · Education & Certifications · Contact

## Tech

React 18 · Vite · Tailwind CSS · Framer Motion · lucide-react

## Run locally

```bash
npm ci
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

## Updating content

- Contact details, experience, education and certifications: `src/data/profile.js`
- Projects: `src/components/Projects.jsx`
- Skills: `src/components/Skills.jsx`
- Resume: replace `public/resume.pdf`
